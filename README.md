# To-Do List Management System

A beginner-friendly, menu-driven task manager written in Python. It helps users organize tasks by title, category, priority, and status.

## Features

- Add, view, update, and delete tasks
- Mark tasks as completed
- Search tasks by title or category
- Filter tasks by priority
- Display pending and completed tasks
- Count tasks and view completion progress
- Remove all completed tasks

## Requirements

- Python 3
- No external libraries required
